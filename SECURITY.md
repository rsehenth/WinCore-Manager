# Security policy

## Supported versions

The latest version on the default branch.

## Reporting a vulnerability

Please do not open a public issue with vulnerability details.

Use **Security → Report a vulnerability** on this repository (GitHub private vulnerability reporting). If that option is not available, open an issue that only asks for a private contact channel, with no technical details.

Include the version, the Windows version, steps to reproduce and the expected impact. Remove personal data from logs and screenshots.

Elevation, file and registry removal, update and recovery paths are the most sensitive areas.
