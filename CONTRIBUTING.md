# Contributing

Contributions in English or Portuguese are welcome.

1. Open an issue describing the problem or proposal before large changes.
2. Fork and create a branch.
3. Build and test on Windows with the .NET 10 SDK (see [README](README.md#building-from-source)).
4. Keep both languages in sync when changing interface text (`Strings.resx` and `Strings.en-US.resx`).
5. Open a pull request that says what changed, why, and how you verified it.

Tests must use fixtures and fakes. They must not install, update or uninstall software, or change real system settings.

Do not include personal data, logs, databases or credentials in issues, commits or screenshots.
